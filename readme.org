#+TITLE: hs_emacs_helper

A Hammerspoon spoon for Emacs automation and message display.

* Features

- **Emacs Control**: Activate Emacs and execute elisp code via emacsclient
- **Message Display**: Show temporary on-screen messages and a menubar for messages
- **No Dependencies**: Uses only core Hammerspoon APIs

* Core Methods

** Emacs Control
- =emacs_execute(elisp)= - Execute elisp code (with proper shell escaping)
- =focus_emacs()= - Activate Emacs application
- =emacs_is_front_app()= - Check if Emacs is frontmost

** Message Display
- =message(message)= - Show temporary on-screen message (auto-hides after 3s)
- =update_menu_message(message)= - Update menubar status
- =message_hide()= - Hide the message canvas
- =reset_menu_message()= - Reset menubar to empty state

* Configuration

- =emacsClient= - Path to emacsclient (default: /opt/homebrew/bin/emacsclient)
- =msgShowDuration= - Message display duration in seconds (default: 3)

* Usage

** Loading the Spoon

Load the spoon and add convenience methods:

#+BEGIN_SRC lua
local emh = hs.loadSpoon("hs_emacs_helper")

function emacs_org_roam_capture(template)
  if template then
    emh:emacs_execute(string.format('(org-roam-capture nil "%s")', template))
  else
    emh:emacs_execute('(org-roam-capture)')
  end
end

function emacs_agenda()
  emh:emacs_execute("(org-agenda)")
end

-- whenever this key is pressed, if emacs is not the current app, summon it
-- and pass the keys to it
-- otherwise simply pass the keys directly to emacs

keyId1 = emh:bind_key_to_emacs({"cmd", "ctrl"}, "c")
keyId2 = emh:bind_key_to_emacs({"ctrl"}, "x")

-- disable key
emh:toggle_key_to_emacs(keyId1, false)
-- enable
emh:toggle_key_to_emacs(keyId1, true)
-- toggle
emh:toggle_key_to_emacs(keyId1)

-- disable all keys
emh:toggle_all_keys_to_emacs(false)

-- enable all keys
emh:toggle_all_keys_to_emacs(true)

#+END_SRC

** Other Usage

Execute elisp code:
#+BEGIN_SRC lua
emh:emacs_execute('(message "Hello from Emacs")')
#+END_SRC

Activate Emacs:
#+BEGIN_SRC lua
emh:focus_emacs()
#+END_SRC

Toggle hotkey state:
#+BEGIN_SRC lua
emh:toggle_key_to_emacs(keyId)           -- Toggle specific hotkey
emh:toggle_all_keys_to_emacs(true)       -- Enable all hotkeys
emh:toggle_all_keys_to_emacs(false)      -- Disable all hotkeys
#+END_SRC

* Assumptions

- emacs always has at least one window open
- emacs is running in server mode
- emacsclient is available at the configured path
